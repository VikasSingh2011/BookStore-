# BookStore - Full Stack MERN Application Live Link- https://book-store-x4ay-git-main-vikas-singhs-projects-b53a535f.vercel.app/

## 📖 Description
BookStore is a full-stack MERN application that allows users to browse, search, 
and purchase books online. It also provides authentication and a course section
for free and paid content.

## ✨ Features
- User Signup & Login
- Browse books
- Free & Paid Courses
- Search functionality
- Responsive UI
- Admin book management

## 🛠 Tech Stack

Frontend:
- React (Vite)
- Tailwind CSS
- DaisyUI
- Axios

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose

## ▶️ How to Run

1. Clone the repository
git clone https://github.com/VikasSingh2011/BookStore-.git

2. Start Backend
cd Backend
npm install
npm run dev

3. Start Frontend
cd ../Frontend
npm install
npm run dev
